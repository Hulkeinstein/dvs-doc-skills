# DVS 문서 스킬

안티그래비티(그리고 `SKILL.md`를 읽는 다른 AI 도구)가 엑셀 · 워드 · 파워포인트 · PDF 파일을 만들고, 읽고, 고치게 하는 스킬 묶음이다. DVS 「안티그래비티 왕초보편」 6강 「결과를 내가 쓰는 파일로 받기」에서 나눠 주는 스킬이다.

| 폴더 | 하는 일 |
|---|---|
| `dvs-office` | 공용 도구 — 설치 확인, 파일을 그림으로 바꿔 눈으로 확인, PDF로 바꾸기, 엑셀 수식 다시 계산, 양식 파일(.dotx · .potx · .xltx) 열기 · 저장 |
| `dvs-xlsx` | 엑셀: 새로 만들기 · 읽기 · 고치기 · 정리 · 차트 · 수식 확인 · csv 바꾸기 |
| `dvs-docx` | 워드: 새로 만들기(목차 · 쪽 번호 · 머리글) · 고치기 · 찾아 바꾸기 · 그림 · 메모 · 변경 내용 추적 |
| `dvs-pptx` | 파워포인트: 새로 만들기 · 고치기 · 합치기 · 나누기 · 발표자 메모 · 디자인 규칙 · 화면 확인 |
| `dvs-pdf` | PDF: 만들기 · 글 · 표 읽기 · 합치기 · 나누기 · 돌리기 · 워터마크 · 서식 칸 채우기 · 암호 · 스캔 글자 읽기 |

## 설치 (시청자)

1. 가장 쉬운 방법: 안티그래비티에 이 저장소 주소를 주고 「이 스킬들 내 전역 스킬 폴더에 설치해 줘. 바로가기 말고 폴더째 복사해서 넣어 줘」라고 말한다(안티그래비티는 바로가기·연결로 넣은 스킬 폴더를 읽지 않는다). 직접 하려면 이 저장소의 `skills` 폴더 안 다섯 폴더를 통째로 `내 사용자 폴더\.gemini\config\skills\`에 넣는다(모든 프로젝트에서 쓰기). 한 프로젝트에서만 쓰려면 그 프로젝트의 `.agents\skills\`에 넣는다.
2. 안티그래비티를 다시 열고 Customizations → Installed → Skills & Rules에 다섯 개가 보이는지 확인한다.
3. 처음 쓸 때 AI가 필요한 프로그램(파이썬 도구 · LibreOffice 등)을 확인하고, 없으면 **설치해도 되는지 묻고** 설치한다.
4. 스캔한 한글 문서를 읽으려면 Tesseract에 한국어 데이터를 한 번 더 넣는다(관리자 권한 필요 없음 — `dvs-pdf` 스킬의 「스캔본 한국어 준비」).

## 알려진 제한

- 일부 Windows PC는 보안 기능(앱 제어)이 pandas를 막는다. 그래도 스킬은 openpyxl만으로 동작한다.
- PDF 양식 칸의 한글은 보기 프로그램이 다시 그려 보여 준다 — 일부 휴대폰 · Mac 미리보기에서는 비어 보일 수 있다.
- Mac · Linux에서 PDF를 만들 때는 나눔고딕 같은 TrueType 한글 글꼴이 있어야 한다.
- 2026-11-06 Windows 11에서 모든 명령을 한글 예제 파일로 실행해 확인했다. Mac · Linux는 아직 실행해 보지 않았다.

## 만든 원칙

- 기능은 널리 쓰이는 문서 스킬과 같은 범위를 목표로 하되, 글과 코드는 처음부터 새로 썼다(다른 회사 스킬의 문장 · 코드를 옮기지 않음 — 사용 조건).
- 공개 도구만 쓴다: openpyxl · pandas · python-docx · python-pptx · pypdf · pdfplumber · reportlab · pypdfium2 · pytesseract · LibreOffice · Tesseract.
- 한국어 문서가 기본이다: 한글 글꼴(맑은 고딕 · 나눔고딕 · Noto Sans KR)을 찾아 쓴다.
- 원본 파일은 덮어쓰지 않는다 — 모든 고치기 명령은 새 이름으로 저장한다.
